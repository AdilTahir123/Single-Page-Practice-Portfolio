# Single Page Practice Portfolio 💻

A responsive single-page personal portfolio website built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

[View Live Portfolio](https://single-page-practice-portfolio.vercel.app/)

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Sheets
- Vercel

## ✨ Features

- Responsive single-page design
- Personal portfolio sections
- About section
- Skills section
- Projects section
- Contact form
- Contact form connected with Google Sheets
- Responsive layout for different screen sizes
- Clean and interactive UI

## 📚 About This Project

This is my personal practice portfolio website, created to improve my frontend development skills.

The project focuses on responsive design, UI development, CSS styling, JavaScript functionality, and form integration with Google Sheets.

## 🌐 Deployment

The portfolio is deployed using Vercel.
